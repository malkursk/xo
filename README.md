# ТЕХНИЧЕСКОЕ ОПИСАНИЕ РАЗРАБОТКИ
## Модуль управления семинарами для Telegram Bot + Django API
**Статус проекта**: Завершен и готов к эксплуатации

## требуется экспертиза для оценки и оплаты работ

---

## КРАТКОЕ ОПИСАНИЕ

Выполнена комплексная разработка системы управления семинарами с полной интеграцией в существующую платформу обращений. Проект включает создание нового функционала для организации и проведения семинаров, регистрации участников через Telegram-бота, а также административного интерфейса для управления мероприятиями.

---

## 1. BACKEND РАЗРАБОТКА (Django Framework)

### 1.1 Проектирование и создание моделей данных

**Модель Seminar** - основная сущность для управления семинарами:
- Реализованы все необходимые поля: название, описание, дата окончания регистрации
- Добавлены системные поля для отслеживания времени создания и изменения
- Создан флаг активности для управления видимостью семинаров
- Реализованы вычисляемые свойства для проверки статуса регистрации и подсчета участников

**Модель SeminarRegistration** - управление регистрациями участников:
- Установлены связи с моделями семинаров и заявителей
- Реализована возможность прикрепления вопросов через связь с системой обращений
- Добавлен механизм отмены регистрации с сохранением истории
- Обеспечена уникальность регистрации одного пользователя на семинар

### 1.2 API архитектура и endpoints

Создан полноценный REST API для управления семинарами:

**CRUD операции**:
- `GET /api/seminars/` - получение списка семинаров с поддержкой фильтрации по активности и срокам
- `GET /api/seminars/{id}/` - получение детальной информации о конкретном семинаре
- `POST /api/seminars/` - создание нового семинара с валидацией входных данных
- `PUT/PATCH /api/seminars/{id}/` - обновление информации о семинаре
- `DELETE /api/seminars/{id}/` - удаление семинара

**Специализированные endpoints**:
- `GET /api/seminars/{id}/statistics/` - получение детальной статистики по семинару включая количество регистраций, отмененных записей и вопросов

### 1.3 Сериализация данных

**SeminarSerializer** обеспечивает:
- Правильное форматирование дат в ISO 8601 формате
- Включение вычисляемых полей (статус регистрации, количество участников)
- Валидацию входных данных при создании и изменении семинаров

**SeminarRegistrationSerializer** предоставляет:
- Вложенные данные об участниках и семинарах
- Информацию о связанных вопросах
- Статистические данные для аналитики

**SeminarStatisticsSerializer** генерирует:
- Агрегированную статистику по семинару
- Детальную информацию о всех регистрациях
- Метрики активности и вовлеченности участников

### 1.4 Административный интерфейс

Создан удобный интерфейс администратора с:
- Фильтрацией семинаров по статусу и дате
- Поиском по названию и описанию
- Отображением количества регистраций в реальном времени
- Управлением регистрациями участников с возможностью просмотра связанных вопросов

## 2. TELEGRAM BOT РАЗРАБОТКА

### 2.1 Архитектура состояний (Finite State Machine)

Реализована сложная система управления состояниями пользователя:

**SeminarStates.asking_question** - выбор действия после регистрации:
- Пользователь может выбрать между созданием вопроса или пропуском этого шага
- Обработка пользовательского ввода с валидацией доступных опций
- Переход к следующему состоянию или завершение процесса

**SeminarStates.waiting_for_question_text** - ввод текста вопроса:
- Прием и валидация текста вопроса от пользователя
- Создание связанного обращения в системе
- Автоматическое форматирование с указанием семинара

**SeminarStates.waiting_for_files** - прикрепление файлов:
- Обработка до 5 файлов различных типов
- Поддержка документов и изображений
- Конвертация в base64 для передачи через API

### 2.2 Интерактивный пользовательский интерфейс

**Inline клавиатуры**:
- Кнопки регистрации на семинар с передачей ID
- Кнопки отмены регистрации
- Навигационные элементы для возврата к списку

**Reply клавиатуры**:
- Динамические клавиатуры в зависимости от контекста
- Кнопки выбора действий (задать вопрос/пропустить)
- Кнопка завершения процесса прикрепления файлов

### 2.3 Интеграция с базой данных

Создан набор асинхронных функций для работы с Django ORM:

**get_active_seminars()** - получение активных семинаров:
- Фильтрация по статусу активности
- Исключение семинаров с истекшим сроком регистрации
- Сортировка по дате окончания регистрации

**create_registration()** - создание регистрации:
- Проверка существующих регистраций
- Атомарное создание записи
- Обработка ошибок дублирования

**create_seminar_question()** - создание вопроса:
- Интеграция с системой обращений
- Автоматическая категоризация
- Связывание с регистрацией на семинар

### 2.4 Обработка медиа-контента

Реализована система загрузки и обработки файлов:
- Поддержка документов любого типа (PDF, DOC, TXT и др.)
- Обработка изображений в форматах JPG, PNG
- Автоматическое именование файлов
- Кодирование в base64 для передачи через API
- Ограничение на количество файлов (максимум 5)

## 3. СИСТЕМНАЯ ИНТЕГРАЦИЯ И АРХИТЕКТУРА

### 3.1 Интеграция с существующей системой обращений

Семинарский модуль полностью интегрирован с существующей системой:
- Вопросы к семинарам создаются как стандартные обращения (Appeal)
- Использование существующей системы категорий и статусов
- Сохранение всех возможностей обработки (ответы администраторов, файлы, история)
- Отображение семинарских вопросов в общем списке обращений пользователя

### 3.2 Валидация и бизнес-логика

**Временные ограничения**:
- Проверка актуальности семинара при попытке регистрации
- Автоматическое скрытие семинаров с истекшим сроком
- Валидация дат при создании новых семинаров через API

**Ограничения регистрации**:
- Предотвращение повторной регистрации на один семинар
- Обработка отмененных регистраций
- Возможность повторной регистрации после отмены

**Файловые ограничения**:
- Лимит на количество файлов при создании вопроса
- Проверка типов файлов
- Обработка ошибок загрузки

### 3.3 Система ошибок и уведомлений

Добавлены новые коды ошибок:
- `SEMINAR_NOT_FOUND` - семинар не найден
- `SEMINAR_REGISTRATION_CLOSED` - регистрация закрыта

Реализована система уведомлений пользователей:
- Информирование об успешной регистрации
- Уведомления об ошибках с понятными объяснениями
- Подтверждения действий (отмена регистрации, создание вопроса)
